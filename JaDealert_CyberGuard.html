Cyber Hygiene
BEST PRACTICES & PROTOCOLS

✓ DO's

  • Use strong, unique passwords for every account
  • Enable two-factor authentication everywhere
  • Verify URLs before entering credentials
  • Keep all software and OS updated
  • Use a password manager
  • Back up data regularly
  • Use HTTPS websites only
  • Check sender email domains carefully
  • Log out from public computers
  • Monitor bank statements regularly

✕ DON'Ts

  • Never share OTPs with anyone, ever
  • Don't click links in unsolicited emails
  • Don't reuse passwords across sites
  • Never use public WiFi for banking
  • Don't ignore security update prompts
  • Never download from unknown sources
  • Don't share personal info on social media
  • Never store passwords in plain text
  • Don't trust urgent "act now" messages
  • Never scan unknown QR codes blindly
